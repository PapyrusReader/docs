Contributor proposals
=====================

This directory holds implementation proposals and task-specific working documents.
It is excluded from the published Sphinx site, navigation, search and requirement
export. Proposals are reviewed through their linked issues and pull requests.

The published documentation contains the user manual, product requirements and
the system's documented structure and behavior. A proposal does not establish
that a feature exists or that a requirement has been accepted as complete.
After implementation, update the relevant maintained documentation with the
resulting behavior. Keep execution plans, rollout checklists and review evidence
with the proposal or its issue instead of copying them into system design pages.
